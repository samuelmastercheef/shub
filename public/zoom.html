Kết nối Socin

Khoá Zoom SDK (Client ID, Client Secret) nằm trong admin Socin, không cần ở đây. Không dùng file .env.
  1. Đã liên kết theo tài khoản Socin thì bỏ qua bước này. Nếu chưa: mở Socin → Cài đặt → 🎥 Zoom → Tạo khoá worker, sao chép (chỉ hiện một lần), dán vào ô trên → Lưu.
  2. Cài / cập nhật worker (lần đầu) → Bật worker.
  3. Quay lại Socin bấm 🔌 Kiểm tra kết nối: mục "Worker đang liên lạc" phải đạt.
